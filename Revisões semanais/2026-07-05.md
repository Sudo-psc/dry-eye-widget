# Revisão Semanal - 2026-07-05

## Resumo das Alterações (Última Semana)
Na última semana (referente ao merge de 14 commits para a v1.20.0), houve um refatoramento massivo de UX e a introdução de novos recursos:
- **Design System (`lib/ui/`)**: Introdução de um tema padronizado (`AppTheme`), cores semânticas (`AppSemanticColors`), fontes locais embutidas (`Inter` e `RobotoMono`), abandonando dependência de `google_fonts`.
- **Componentes de UI Novos**: Foram criados componentes como `ScoreGauge` animado, `GlassCard`, `TrendLineChart` (gráfico de área com escala configurável), `ProgressRing`, `StatTile`, `SectionHeader` e `BreathingCircle`.
- **Substituição do Questionário OSDI pelo DVRS**: Remoção completa do código OSDI (`osdi_assessment`, `osdi_dialog`, etc) e substituição pelo Digital Vision Risk Score (DVRS) - com modelos, lógica de avaliação (`dvrs_engine`), telas e suporte a PDF report novos.
- **Pausa Aprimorada**: A tela de pausa suave (gentle break) agora conta com anel de progresso, funcionalidade de respiração guiada e streaks.
- **Dashboard e Menu**: O Dashboard recebeu uma nova aba de "Resumo" com KPIs, e gráficos sparkline em relação ao tempo de tela e mini gauge para o DVRS. O menu flutuante agora tem cores diferentes por grupo (com destaque para o DVRS).
- **Landing Page (`site/`)**: Atualização de screenshots e scripts da landing page para refletir a nova interface.

## Revisão de Código e Falhas/Melhorias Sugeridas
### 1. Dependências do Projeto
- **Falha:** `flutter analyze` e `flutter test` estão falhando atualmente porque há uma restrição de versão no `pubspec.yaml` que exige o SDK do Flutter `>=3.44.0` e SDK do Dart `>=3.12.0 <4.0.0`, porém a máquina (ou pipeline de CI/CD) está com o Flutter 3.41.2 e Dart 3.11.0. (De acordo com a memória, não devemos alterar o pubspec.yaml para contornar isso, mas é crucial garantir que a pipeline/sandbox ou dev environment seja atualizada para rodar o SDK 3.44.0).
### 2. Design System
- **Melhoria (`lib/ui/app_theme.dart`):** A estrutura de design centraliza as cores usando `ThemeExtension<AppSemanticColors>`. Isso é uma excelente prática. Pode ser interessante criar também um `ThemeExtension` para gerenciar tipografia (se houver fontes/textos customizados além dos básicos do M3).
### 3. Integração Platform-Specific
- **Revisão Positiva:** A verificação por `Platform.is` não retornou ocorrências em todo `lib/`, alinhado com as orientações (memória de usar `defaultTargetPlatform`).
### 4. Empacotamento / Segurança
- **Revisão:** As dependências do `pubspec.yaml` mostram o pacote `share_plus` fixo na versão `^12.0.2` para evitar problemas com dependências de `win32` associadas ao `launch_at_startup`. É uma solução válida, mas deve-se monitorar atualizações futuras de segurança do pacote `launch_at_startup`.
### 5. Cobertura de Testes
- **Revisão:** Diversos testes unitários foram adicionados (ex: `dvrs_engine_test.dart`, `trend_line_chart_test.dart`). Apesar do `flutter test` não rodar devido ao conflito de SDK, o commit history relata '167 testes verdes'.

## Próxima Ação Sugerida
1. **Atualizar o ambiente de CI/CD / Desenvolvimento**: É fundamental atualizar o SDK do Flutter (para 3.44.x) na máquina/pipeline para que os testes e a análise estática possam ser executados de forma confiável.
2. **Validar Landing Page e Assets**: Verificar os assets recém-adicionados no `site/` e realizar um smoke test na landing page para confirmar se os novos screenshots e estilos estão corretos em todos os viewports.
3. **Acompanhar Feedbacks do DVRS**: Com a mudança de OSDI para DVRS, acompanhar o uso do usuário e logs para ver se o novo formulário de avaliação está performando bem.
